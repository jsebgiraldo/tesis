# Obsidian + Git (Vault de la Tesis)

Este repo está configurado para funcionar como **Vault de Obsidian**.

## Abrir en Obsidian

1. Obsidian → *Open folder as vault*
2. Selecciona esta carpeta: `tesis/`

## Convenciones

- MOC principal: `00_Mapa_Tesis.md`
- Canvas principal: `00_Mapa_Tesis.canvas`
- Capítulos: `capitulos/`
- Conceptos: `conceptos/`
- Fuentes: `fuentes/`

## Git

Se versiona el contenido del vault (notas, canvas, estructura). Se ignoran archivos locales volátiles de Obsidian (workspace/caches).

## Plugins (recomendados)

- **Dataview** (consultas y listas automáticas)
- **Citations** (si conectas Zotero / BibTeX)

> Nota: la instalación/activación de plugins se hace desde la UI de Obsidian.
