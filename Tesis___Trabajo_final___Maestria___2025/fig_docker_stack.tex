\caption{Arquitectura Docker Compose del stack de microservicios en Gateway Edge mostrando 6 contenedores orquestados con redes virtuales y volúmenes persistentes. Contenedor principal gateway\_service (Python FastAPI, 512 MB RAM, 1 CPU) implementa parsing DLMS/COSEM, transformación LwM2M, cliente CoAP, motor agregación 5-min, expone API REST puerto 8000. InfluxDB 2.7 (256 MB RAM) almacena time-series métricas con bucket iot\_metrics retention 90 días, volumen persistente 5 GB. Redis 7.0 (128 MB RAM) provee cache LRU y message queue para desacoplamiento temporal. Eclipse Mosquitto 2.0 (64 MB RAM) broker MQTT puertos 1883/8883 con autenticación username/password para suscriptores cloud. Grafana 10.2 (256 MB RAM) renderiza 3 dashboards preconfigured consumiendo InfluxDB datasource, puerto 3000 local. Nginx 1.25 (64 MB RAM) reverse proxy TLS 1.3 con Let's Encrypt mapea puerto 80→8000 (gateway API) y 443→3000 (Grafana UI). Red Docker backend (172.20.0.0/24) aísla servicios internos (InfluxDB, Redis, Mosquitto, gateway\_service), red frontend expone Nginx y Grafana al host. Volúmenes persistentes totalizan 7 GB: influxdb\_data 5 GB, app\_logs 1 GB, redis\_data 500 MB, grafana\_dashboards 200 MB, mosquitto\_config 100 MB, nginx\_certs 50 MB. Stack consume 1.28 GB RAM total (32\% de 4 GB RPi4), 2.6 CPU cores pico, uptime 99.1\% durante piloto. Restart policy unless-stopped con health checks 30s interval garantizan auto-recuperación fallas. Entrada CoAP UDP 5683 desde Thread Border Router (30 nodos IoT), entrada DLMS/COSEM RS-485 /dev/ttyUSB0 @ 9600 bps, salida HTTPS/MQTT HaLow mesh hacia cloud. Logging json-file limitado 100 MB por contenedor evita saturación disco SD. Arquitectura microservicios permite escalado horizontal independiente de componentes y rollback granular en actualizaciones.}
\label{fig:docker-stack}
