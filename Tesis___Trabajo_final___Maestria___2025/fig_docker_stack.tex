\caption{Arquitectura Docker Compose de ThingsBoard Edge en la pasarela RPi4 (OpenWRT 23.05).  El \emph{stack} comprende 3~contenedores: (1)~ThingsBoard Edge 3.6.2 (monolito JVM con transporte LwM2M integrado, motor de reglas, gestor de nube y panel web), (2)~PostgreSQL~15 (almacenamiento relacional y de series temporales) y (3)~Redis~7.0 (cach\'{e}).  OTBR se ejecuta como servicio nativo de OpenWRT (fuera de Docker).  El flujo de datos: nodos Thread $\rightarrow$ OTBR (IPv6) $\rightarrow$ TB Edge (LwM2M :5685) $\rightarrow$ procesamiento local (reglas RC1--RC4) $\rightarrow$ sincronizaci\'{o}n gRPC con servidor \emph{on-premise}.  Recursos totales: $\sim$2,5 CPU, $\sim$1\,800\,MB RAM.}
