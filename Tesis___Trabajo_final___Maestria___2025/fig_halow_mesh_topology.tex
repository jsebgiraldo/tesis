\caption{Topología HaLow Mesh peer-to-peer con Gateways Edge distribuidos. Red HaLow (capa superior) comprende 3 routers Alfa Networks Tube AHM formando mesh IEEE 802.11s full-mesh con protocolo HWMP: 1 Mesh Gate (Tube-01) dedicado con backhaul Ethernet a switch local (server on-premise conectado al mismo switch, detallado Capítulo 5), y 2 Mesh Points peer (Tube-02, Tube-03) con gateways RPi4 integrados por Ethernet local operando como nodos mesh equipolentes sin jerarquía. Gateways Raspberry Pi 4 (capa intermedia, RPi4-01 y RPi4-02) son Mesh Points activos que participan directamente en routing HWMP cooperativo, inyectando tráfico agregado Thread al backbone HaLow compartido, ejecutando ThingsBoard Edge y OTBR. Arquitectura distribuida peer elimina single-point-of-failure: protocolo HWMP mantiene múltiples paths redundantes entre todos los Mesh Points, re-enrutando automáticamente ante fallos de cualquier nodo. Nodos Thread (capa inferior) forman mesh IEEE 802.15.4 conectado a cada gateway vía nRF52840 Dongle USB. Este capítulo enfoca en red HaLow mesh 802.11s distribuida; conectividad WAN se documenta Capítulo 5.}
